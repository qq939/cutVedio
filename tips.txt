# VS Code Tips for Mac

## Shortcuts
- **Command Palette**: `Cmd + Shift + P` (Access all commands)
- **Quick Open File**: `Cmd + P` (Quickly find files by name)
- **Multi-Cursor**: `Opt + Click` (Add multiple cursors) or `Cmd + Option + Up/Down`
- **Toggle Terminal**: `Ctrl + ` ` (Backtick)
- **Toggle Line Comment**: `Cmd + /`
- **Format Document**: `Shift + Option + F`
- **Go to Definition**: `F12` or `Cmd + Click`
- **Trigger Suggestion**: `Ctrl + Space`

## Python Specific
- **Select Interpreter**: `Cmd + Shift + P` -> "Python: Select Interpreter" (Select the one in .venv)
- **Run Python File**: `Cmd + Option + N` (if Code Runner extension installed) or use Terminal

## Git
- **Git Commit**: `Cmd + Enter` (in Source Control view)
- **Git Push**: `Cmd + Shift + P` -> "Git: Push"

## Code Completion
- Type a few characters and press `Tab` or `Enter` to accept suggestions.
- `Ctrl + Space` to force trigger suggestions if they don't appear.
